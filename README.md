# San Remo CRM

Base inicial do CRM imobiliário da San Remo, criada com React, TypeScript e Vite.

## Requisitos

- Node.js 20.19 ou superior
- npm 10 ou superior

## Como executar

```bash
npm install
npm run dev
```

O servidor de desenvolvimento informará no terminal o endereço local da aplicação.

## Build de produção

```bash
npm run build
```

Os arquivos gerados serão salvos em `dist/`.

## Variáveis de ambiente

Use `.env.example` como referência ao adicionar variáveis de ambiente no futuro. Não armazene credenciais no repositório.

## Estado atual

Este repositório contém somente a estrutura inicial da aplicação. Integrações e funcionalidades do CRM serão adicionadas em etapas futuras.
