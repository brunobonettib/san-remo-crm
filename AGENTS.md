
# San Remo — Instruções para Codex

## Objetivo
Implementar um CRM imobiliário Full Stack para desafio técnico.

## Stack
React, TypeScript, Supabase Auth, PostgreSQL, RLS e Vercel.

## Regras
- Trabalhar em uma tarefa delimitada por vez.
- Ler somente os arquivos relevantes à tarefa.
- Manter código simples, legível e organizado.
- Não adicionar dependências sem necessidade.
- Não refatorar componentes não relacionados.
- Preservar funcionalidades existentes.
- Não criar recursos fora dos requisitos.
- Proteger operações sensíveis no backend.
- Nunca expor segredos ou chaves privilegiadas.
- Validar build e testes relevantes após alterações.

## Regras críticas
- QR Code vigente por 5 minutos.
- Presença válida por 5 horas.
- Renovação válida mantém posição na fila.
- Retorno após expiração entra no final.
- Distribuição round-robin consistente.
- Lead não pode ser atribuído duas vezes.
- Gestor e corretor têm permissões distintas.

## Ao finalizar cada tarefa
Responder brevemente:
1. O que foi implementado.
2. Arquivos alterados.
3. Testes executados e resultados.
4. Problemas ainda existentes.

Não realizar alterações fora do escopo solicitado.
